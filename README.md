# Car Freios

Landing page da oficina Car Freios, em Campinas, SP.

Site publicado: https://car-freios-campinas.vercel.app/

## Tecnologias

HTML, CSS e JavaScript, sem dependências ou etapa de compilação.

## Visualização local

Abra index.html ou execute um servidor estático na pasta do projeto:

    python -m http.server 8000

Acesse http://localhost:8000.

## Edição

- index.html: conteúdo e estrutura.
- styles.css: aparência e responsividade.
- script.js: navegação, entradas animadas e galeria.
- assets/: logo e imagens utilizadas.

## Vercel

Importe este repositório como projeto estático, com preset Other, sem comando de build e diretório de saída na raiz. O site existente não precisa ser substituído para armazenar o código no GitHub.

## Imagens e conteúdo

Logo e imagens fornecidos pelo cliente. Registros da oficina identificados como provenientes do Google Maps; preserve atribuições. Não há licença concedendo a terceiros permissão para reutilizar essas imagens.

Avaliação e informações comerciais são os dados fornecidos pelo cliente, sem sincronização automática com o Google.
